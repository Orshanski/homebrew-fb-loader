# homebrew-fb-loader

Homebrew tap for [FB Loader](https://github.com/Orshanski/fb-loader) — macOS browser for FB2 library catalogs from Flibusta INPX dumps.

## Install

```bash
brew tap orshanski/fb-loader
brew install --cask fb-loader
```

## Update

```bash
brew upgrade --cask fb-loader
```

## Uninstall

```bash
brew uninstall --cask fb-loader
```
