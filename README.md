# homebrew-fb-loader

Homebrew tap для [FB Loader](https://github.com/Orshanski/fb-loader) — нативного macOS-каталогизатора офлайн-библиотек Flibusta из INPX-дампов.

## Что такое FB Loader

Работает с архивом библиотеки Flibusta с FB2-архивами на диске — FB Loader открывает их как каталог: можно листать, искать, читать аннотации, выгружать выбранные книги в нужное место. Работает только оффлайн. 

## Возможности

- **Каталог по авторам, сериям, жанрам** — три способа сгруппировать одну и ту же библиотеку, переключение в одном клике.
- **Фильтр по языку** — отдельная секция для книг с неуказанным языком.
- **Нечёткий поиск с опечатками** — искать по фрагменту имени автора, названию книги или серии. Допускает 1-2 опечатки, ищет по частичным совпадениям. Работает на полной библиотеке в полмиллиона книг за полсекунды.
- **Карточка книги** — обложка, аннотация, серия, жанры, размер файла, дата добавления.
- **Массовый экспорт** — отметьте нужные книги чекбоксами и выберите папку: получите `<выбранная папка>/<автор>/<название книги>.fb2` для каждой книги. Папка экспорта запоминается для следующего раза. Подробности — ниже.
- **Бинарный кэш каталога** — INPX парсится один раз и складывается в компактный бинарник, дальше открытие происходит из него. На время загрузки видна заставка с крутилкой и текстом, что приложение делает прямо сейчас («Считаем индексы поиска…», счётчик прочитанных книг и т. п.) — не остаётся в неведении. Если INPX-файл обновился (новые книги в зеркале) — приложение само замечает это по контрольной сумме и пересобирает кэш при следующем запуске. Никаких действий вручную не нужно.

## Установка

```bash
brew tap orshanski/fb-loader
brew install --cask fb-loader
```

После установки откройте `FB Loader` через Spotlight или Launchpad.

## Первый запуск

При первом запуске откроется онбординг-экран:

1. Нажмите **«Выбрать INPX…»** и укажите ваш `.inpx` файл.
2. Нажмите **«Продолжить»** — папка с zip-архивами по умолчанию подставится как директория, где лежит INPX.
3. Подождите, пока каталог парсится — потом откроется главное окно.

Если у вас split-setup (INPX и архивы в разных местах), отдельно настроить путь к архивам можно после онбординга в **Настройках** (`⌘,`).

## Как именуются файлы при экспорте

Структура: `<выбранная папка>/<автор>/<название книги>.fb2`.

**Имя автора в названии папки** определяется так:
- Если в сайдбаре главного окна выбран автор — папка называется именем этого автора (даже если он не первый соавтор у конкретной книги).
- Иначе — берётся первый автор книги.
- Если у книги вообще нет указанного автора — папка называется «(Без автора)».

Формат имени автора: `Фамилия Имя Отчество` (пустые поля опускаются, оставшиеся склеиваются пробелом). Серия в имени папки не используется — даже если в сайдбаре выбрана конкретная серия, книги всё равно раскладываются по авторам.

**Очистка имён.** В именах папки и файла символы `: / \ ? * < > | "` заменяются на `_`, длина каждой части обрезается до 220 байт UTF-8, пробелы по краям удаляются. Без транслитерации, без шаблонов — что у книги в метаданных, то и в имени.

## Если зеркало обновилось

Просто перезапустите приложение — оно само заметит, что контрольная сумма INPX поменялась, и пересоберёт каталог. Если хочется форс-пересборку (например, на случай повреждения кэша) — в **Настройках** (`⌘,`) есть кнопка **«Пересобрать каталог»**.

## Обновление приложения

```bash
brew upgrade --cask fb-loader
```

## Удаление

```bash
brew uninstall --cask fb-loader
```

## Системные требования

macOS 14 (Sonoma) или новее. Apple Silicon и Intel поддерживаются.
